ユーザー本人の管理画面

アカウントセンターは、ユーザー本人が共有アカウントと連携アプリを管理する場所です。 第三者アプリは、ユーザーがこの画面で連携解除や認証設定変更を行えることを前提に設計します。

ユーザーができること

プロフィール確認

表示名、メール、電話番号、公開プロフィール情報を確認します。

連携アプリ管理

接続済みアプリを確認し、不要な連携を解除できます。

認証設定

パスワード、MFA、バックアップコードなどを管理します。

アプリ側の設計ポイント

  • 連携解除後にアプリ側セッションやローカル状態を適切に失効してください。
  • メールアドレスや表示名はユーザー本人が変更できるため、変更に耐えるユーザーモデルにしてください。
  • 退会と共有アカウント削除を混同しないUI文言にしてください。
  • ユーザーに認証設定の変更を案内する場合は、idol-auth側のアカウントセンターへ誘導してください。

公開プロフィール

third-partyアプリに公開されるプロフィールは、ユーザー本人が管理する共有プロフィールのうち許可された範囲に限られます。 生年月日や通知設定など、本人管理用の非公開情報は公開プロフィールとして扱いません。
