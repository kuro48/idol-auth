TypeScript SDK

SDKでログイン導線を実装する

@idol-auth/client はブラウザOAuth2フロー、PKCE helper、token refresh、 logout URL生成、headless auth helperを提供します。

Install

npm install @idol-auth/client

Clientを初期化する

import { IdolAuthClient } from "@idol-auth/client";

const auth = new IdolAuthClient({
  baseUrl: "https://auth.example.com",
});

baseUrl は提供されたidol-authの公開URLに置き換えてください。

ブラウザログイン

await auth.loginWithRedirect({
  clientId: "your-client-id",
  redirectUri: "https://yourapp.example.com/callback",
});

SDKはPKCE verifier / challenge と state を生成し、ブラウザを認可画面へ遷移させます。

Callback処理

const tokens = await auth.handleRedirectCallback();

// tokens.access_token
// tokens.id_token
// tokens.refresh_token

handleRedirectCallback は state 検証と token exchange を行います。 取得したtokenの保存方法はアプリの脅威モデルに合わせて選んでください。

Refreshとlogout

const refreshed = await auth.token({
  grant_type: "refresh_token",
  refresh_token: tokens.refresh_token!,
  client_id: "your-client-id",
});

window.location.href = auth.browserLogoutUrl({
  idTokenHint: tokens.id_token,
  postLogoutRedirectUri: "https://yourapp.example.com/",
});

低レベルPKCE helper

認可URLの生成やstorage管理を自前で行う場合に使います。

import { generatePKCE } from "@idol-auth/client";

const { codeVerifier, codeChallenge } = await generatePKCE();
const loginUrl = auth.browserLoginUrl({
  clientId: "your-client-id",
  redirectUri: "https://yourapp.example.com/callback",
  scope: "openid email profile",
  state: crypto.randomUUID(),
  codeChallenge,
  codeChallengeMethod: "S256",
});

Headless auth

モバイルや一部のバックエンド連携ではheadless helperを利用できます。 Webアプリでは、ユーザーの認証情報をアプリ側で直接扱わないブラウザOAuth2フローを優先してください。 

const result = await auth.login({
  identifier: "user@example.com",
  password: "secure-password",
});

const session = await auth.session(result.session_token);
